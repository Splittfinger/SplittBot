# Security policy

SplittBot is a local macOS agent application. Reports involving permission bypasses, approval bypasses, credential exposure, unsafe local automation, or unexpected data disclosure should not be opened as public issues.

Use GitHub's private vulnerability reporting for this repository. Include the affected version, exact reproduction steps, expected behavior, observed behavior, and whether any external action occurred.

Do not include ChatGPT credentials, OAuth tokens, private conversations, local database files, screenshots, or personal message content in a report. Redact logs before attaching them.

The locally ad-hoc-signed development bundle is not a public release. Supported public versions will be the notarized builds attached to GitHub Releases.
