# Glass workspace previews

Captured from the implemented renderer on September 8, 2026 using the isolated glass-interface acceptance test. Agent names, actions, connection state, model names, and usage values are deterministic sample data, not live account or mailbox results. Native window borders/traffic lights and desktop vibrancy are not captured by renderer-only screenshots.

- `home-light.png`: translucent primary navigation and the standard reading canvas.
- `home-dark.png`: dark appearance.
- `conversation-light.png`: contextual roster, floating controls, optional inspector, and composer.
- `conversation-compact.png`: compact 900 × 640 layout.
- `actions-light.png`: the durable decision queue and action details.
- `tools-light.png`: connection catalog and bot grants.
- `agent-editor-light.png`: agent creation sheet.

Implementation details and platform limitations are in `docs/apple-27-ui.md`.
